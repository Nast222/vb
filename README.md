# 💱 Currency Converter (Конвертер валют)

**Автор:** [Глазунов Алексей]
**Язык:** Python 3.x

## Описание проекта

Это графическое приложение (GUI) для конвертации валют. Оно использует внешний API для получения актуальных курсов и сохраняет историю операций в локальный файл.

## 🛠️ Требования

Для работы программы необходимо установить Python 3 и библиотеку `requests`:
*Примечание:* Библиотека `tkinter` входит в стандартную библиотеку Python.

## 🚀 Запуск приложения

1. Убедитесь, что у вас установлен Python.
2. Скачайте или клонируйте этот репозиторий.
3. Откройте терминал в папке проекта.
4. Запустите скрипт:
   ```bash
   python currency_converter.py
   ```

## ⚙️ Как это работает?

1. **Выбор валют:** Используйте выпадающие списки для выбора исходной и целевой валюты.
2. **Ввод суммы:** Введите сумму в поле. Допускаются только положительные числа.
3. **Конвертация:** Нажмите кнопку «Конвертировать».
4. **История:** Все операции сохраняются в таблице внизу окна и в файле `history.json`.

## 🌐 Использование API

Программа использует бесплатный и открытый API [exchangerate.host](https://exchangerate.host).
*   **Ключ API не требуется** для базовых запросов.
*   Курсы обновляются в реальном времени при каждом нажатии кнопки.
*   Если API недоступен (нет интернета), программа покажет ошибку.

## 📂 Сохранение данных

История ваших операций сохраняется в файл `history.json` в той же папке. Вы можете открыть этот файл любым текстовым редактором или удалить его для очистки истории.
